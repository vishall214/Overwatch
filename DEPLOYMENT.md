# Deployment Guide — Render (Backend) + Vercel (Frontend)

This guide covers deploying the OVERWATCH project with the FastAPI backend on
**Render** and the React + Vite frontend on **Vercel**.

---

## Prerequisites

- GitHub repo pushed: `vishall214/overwatch`
- All config files are already set up in this repo (`render.yaml`, `vercel.json`, `Dockerfile`)

---

## 1. Deploy Backend on Render

### Option A — Blueprint (Recommended)

1. Go to [dashboard.render.com/blueprints](https://dashboard.render.com/blueprints)
2. Click **New Blueprint Instance**
3. Connect your GitHub repo → `vishall214/overwatch`
4. Render reads `render.yaml` and creates the service automatically
5. Set the following env vars in the Render dashboard:

| Variable | Value |
|----------|-------|
| `DATABASE_URL` | Render Postgres internal URL (see "Database" below) |
| `OVERWATCH_CORS_ORIGINS` | `["https://your-app.vercel.app"]` |
| `OVERWATCH_SECRET_KEY` | Auto-generated by Render |
| `OVERWATCH_DEBUG` | `false` |

### Option B — Manual Setup

1. Render Dashboard → **New** → **Web Service**
2. Connect `vishall214/overwatch`
3. Configure:
   - **Root Directory**: `backend`
   - **Environment**: `Docker`
   - **Plan**: Starter ($7/mo) or Free (spins down after 15min inactivity)
4. Add the same env vars from the table above

### Database

- Render Dashboard → **New** → **PostgreSQL**
- Copy the **Internal Database URL**
- Set it as `DATABASE_URL` in the backend service env vars
- If you skip this, the backend falls back to SQLite (works but **ephemeral** — data resets on redeploy)

### YOLO Model Weights

The `yolov8n.pt` model file (~6.5MB) is auto-downloaded by the `ultralytics` library
on first startup if not present in the container. No manual setup needed.

## 2. Deploy Frontend on Vercel

1. Go to [vercel.com/new](https://vercel.com/new)
2. **Import** the `vishall214/overwatch` repo
3. Configure:
   - **Framework Preset**: Vite (auto-detected)
   - **Root Directory**: `frontend`
   - **Build Command**: `npm run build`
   - **Output Directory**: `dist`
4. Add environment variable:

| Variable | Value |
|----------|-------|
| `VITE_API_BASE` | `https://overwatch-backend.onrender.com` (your actual Render URL) |

5. Click **Deploy**

> **Note**: `VITE_API_BASE` is baked into the JS bundle at build time.
> If you change the backend URL later, redeploy the frontend.

---

## 3. Wire CORS

After both services are live:

1. Copy your Vercel URL (e.g. `https://overwatch-abc.vercel.app`)
2. Go to Render → Backend service → **Environment**
3. Set `OVERWATCH_CORS_ORIGINS`:
   ```
   ["https://overwatch-abc.vercel.app"]
   ```
4. Render auto-redeploys with the updated CORS config

---

## 4. Verify

1. **Backend health**: `GET https://your-backend.onrender.com/health`
   - Should return `{"status": "ok", "version": "0.1.0"}`
2. **Frontend**: Open your Vercel URL — should load the dashboard
3. **API connectivity**: Check browser DevTools Network tab for successful API calls
4. **Logs**: Check Render logs and Vercel deployment logs for any errors

---

## 5. Optional — S3 Storage

Local `storage/` is ephemeral in cloud deployments. For persistent snapshots/clips:

1. Set `OVERWATCH_USE_S3=true` in Render env vars
2. Add S3 credentials:
   - `OVERWATCH_S3_BUCKET`
   - `OVERWATCH_S3_REGION`
   - `OVERWATCH_S3_ACCESS_KEY_ID`
   - `OVERWATCH_S3_SECRET_ACCESS_KEY`
   - `OVERWATCH_S3_ENDPOINT_URL` (for MinIO or DigitalOcean Spaces)

## Architecture

```
┌──────────────┐     HTTPS      ┌──────────────────┐
│   Browser    │ ──────────────→│  Vercel CDN      │
│              │                │  (React + Vite)  │
└──────────────┘                └────────┬─────────┘
                                         │ API calls
                                         │ (VITE_API_BASE)
                                         ▼
                                ┌──────────────────┐
                                │  Render           │
                                │  (FastAPI+Docker) │
                                └────────┬─────────┘
                                         │ SQL
                                         ▼
                                ┌──────────────────┐
                                │  Render Postgres  │
                                │  or SQLite        │
                                └──────────────────┘
```
