OVERWATCH
AI & ML Based Video Analysis and Interpretation System
Full Project Context & Design Summary

1️⃣ Problem Statement
NSG operates multiple surveillance systems including:
Fixed CCTV / ICP feeds
Drone / UAV surveillance
Body cams and tactical robots
These systems generate massive volumes of video data that cannot be manually analyzed in real time without missing critical events.
Currently, there is no unified automated system that:
Ingests multiple video sources
Detects objects and faces
Tracks individuals
Analyzes behavior
Generates real-time alerts
Logs evidence for investigation
OVERWATCH aims to solve this using AI/ML-powered video analysis.

2️⃣ Project Objective
To build a scalable AI-powered surveillance system that:
Ingests video feeds
Performs object detection and tracking
Recognizes faces (known vs unknown)
Detects suspicious behaviors
Generates real-time alerts
Logs events and evidence
Provides a monitoring dashboard
Optionally supports mobile alert viewing

3️⃣ Final Scope (Locked Features)
The system will implement:
Core Detection Features

Person detection
Weapon / dangerous object detection
Face detection and recognition (known vs unknown)
Behavior & Event Detection
Intrusion detection (restricted zones)
Loitering detection

🔟 Core Behavioral Logic
Intrusion
If tracked person enters defined polygon zone → Alert.
Loitering
If tracked ID remains in zone > threshold time → Alert.
Abandoned Object
If object appears and owner leaves and object remains > threshold → Alert.
Crowd Detection
If person count in zone > threshold → Alert.
Speed Anomaly
If tracked velocity > threshold → Alert.

1️⃣5️⃣ Final System Identity
OVERWATCH is:
A real-time AI-powered surveillance intelligence engine that transforms raw video streams into structured security events, alerts, and actionable insights using object detection, tracking, face recognition, and rule-based behavioral analysis.

1️⃣6️⃣ One-Line Summary
OVERWATCH uses FastAPI and Python for backend orchestration, YOLOv8 and ByteTrack for real-time object detection and tracking, InsightFace for face recognition, rule-based behavioral analysis for event detection, PostgreSQL and object storage for data management, and a responsive React dashboard for monitoring and alerts, with training performed on an RTX 3050 and optimized CPU inference for deployment.
